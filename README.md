# Webkonzepte – Sitzung 1: Web1

*Seminar im Master Digitale Kommunikation in der Musik- und Entertainmentindustrie an der HMTM*

> Willkommen im Jahr 1995. Der Browser heißt Netscape, das Modem piept, und eure Webseite entsteht aus nichts als Text, Mut und einem Editor.

## Worum geht's?

Das Seminar **Webkonzepte** führt in vier Workshops durch die Geschichte des Webs:

1. **Web1**: Seiten zum Lesen (heute hier)
2. **Web2**: Seiten zum Mitmachen
3. **Web3**: Seiten mit Besitzverhältnissen
4. **Das Web der Zukunft**: Wer weiß das schon?

In dieser ersten Sitzung gehen wir zurück an den Anfang: Wozu wurden Webseiten erfunden, wie sind die ersten entstanden, und wie funktioniert so eine Seite eigentlich? Die beste Methode, das zu verstehen: **selbst eine bauen**.

## Die Spielregeln

- **Editor statt Entwicklungsumgebung**: Mac: TextEdit (auf *Reiner Text* umgestellt), Windows: Editor.
- **Keine KI, kein Internet, kein Copy & Paste von Fremdcode.** Ihr tippt selbst. Tippfehler sind keine Peinlichkeit, sondern der Lehrplan.
- **Eure Seite gehört einem Artist.** Texte und Bilder habt ihr vorab lokal gespeichert, die Seite bleibt auf eurem Rechner.
- **Habt ein bisschen Spaß.** Es gibt am Ende einen Gallery Walk mit Retro-Charme.

## Was ihr heute lernt

| Phase | Thema | Was dabei herauskommt |
|---|---|---|
| 0 | Anatomie einer HTML-Seite | Eine Seite, die „Hallo Welt" sagt |

## So geht's los

1. Repo herunterladen (grüner Button **Code → Download ZIP**) und entpacken.
2. Ordner `webkonzepte` anlegen, `index.html` und der Ordner mit den Bildern müssen darin liegen.
3. `index.html` im Editor öffnen, ändern, speichern.
4. Doppelklick auf die Datei: Sie öffnet sich im Browser.
5. Ändern, speichern, neu laden (`Cmd/Strg + S`, dann `Cmd + R` bzw. `F5`). Wiederholen, bis die Seite gefällt.

## Die häufigsten Stolpersteine

- Die Datei heißt `index.html.txt`: Dateiendungen im Explorer einblenden.
- Der Browser zeigt Code statt Seite: Die Datei wurde als Text gespeichert, nicht als `.html`.
- Das Bild fehlt: Pfad und Dateiname prüfen, Groß- und Kleinschreibung zählt.
- Die ganze Seite ist plötzlich fett: Ein schließender Tag fehlt.
- Es passiert nichts: Gespeichert, aber nicht neu geladen?
